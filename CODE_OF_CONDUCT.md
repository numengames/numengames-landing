# Code of Conduct

`OSS-002` of `STD-015`. This is the short version, and it is meant literally.

## The standard

Be decent. Assume competence and good faith in the person you are replying
to. Disagree with the work, not the person.

Unacceptable: harassment, personal attacks, discriminatory language,
publishing someone's private information, and sustained disruption of
discussion.

## What this repository is about

Technical rigour is not an exception to the above, and politeness is not an
exception to rigour. A review that says "this is wrong, here is the evidence"
is doing its job. A review that says "only an idiot would write this" is not,
and the presence of a real defect does not excuse it.

Claims carry their evidence. Saying "this does not work" without the command
and its output is not a code-of-conduct problem, but it is not a review
either.

## Scope

Applies in this repository — issues, pull requests, reviews, commit messages —
and to anyone representing the project in public spaces.

## Reporting

Report to **conduct@numen.games**. Reports go to the Oracle
([@PabloFMM](https://github.com/PabloFMM)).

What happens next: acknowledgement within 3 working days, and a decision
communicated to the reporter. Responses range from a private correction to
removal of access, proportionate to what happened and whether it repeated.

If your report concerns the Oracle, send it to any other repository
administrator instead.
